# Desafio — Estrutura de Repetição

Atividade complementar ao Trabalho do 1º Bimestre da disciplina de
Algoritmos, desenvolvida no curso de Tecnologia em Análise e
Desenvolvimento de Sistemas (ADS) da Faculdade Senac Curitiba Portão.

## Objetivo

Ampliar o exercício de cálculo do 13º salário para permitir o
processamento de vários funcionários em uma única execução do
programa.

O usuário informa a quantidade de funcionários e, para cada um deles,
o programa lê o salário mensal e a quantidade de meses trabalhados,
calculando e exibindo o respectivo 13º salário.

## Conceitos praticados

- Entrada e saída de dados
- Variáveis
- Operações aritméticas
- Estruturas condicionais
- Estruturas de repetição

## Arquivo

- `main.cpp` — implementação do desafio em C++.

## Observação

O desafio propõe a utilização de uma estrutura de repetição antes de
seu conteúdo ter sido formalmente desenvolvido na disciplina, servindo
como exercício de experimentação e aprofundamento.

## Caráter acadêmico
