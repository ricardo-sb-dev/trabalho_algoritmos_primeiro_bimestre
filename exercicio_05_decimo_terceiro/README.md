# Exercício 05 — Cálculo do 13º Salário

Atividade integrante do Trabalho do 1º Bimestre da disciplina de
Algoritmos, desenvolvida no curso de Tecnologia em Análise e
Desenvolvimento de Sistemas (ADS) da Faculdade Senac Curitiba Portão.

## Objetivo

Desenvolver um programa que leia o salário mensal bruto de um
trabalhador e a quantidade de meses trabalhados no ano, calculando o
valor correspondente ao 13º salário proporcional.

## Conceitos praticados

- Entrada e saída de dados
- Variáveis
- Tipos de dados
- Operações aritméticas
- Expressões

## Arquivo

- `main.cpp` — implementação do exercício em C++.

## Caráter acadêmico

Atividade avaliativa individual da disciplina de Algoritmos.
